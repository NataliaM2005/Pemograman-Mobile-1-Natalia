Hasil implementasi dari aplikasi Android ini adalah sebuah antarmuka sederhana yang memungkinkan pengguna memasukkan nomor telepon melalui kolom input, kemudian menampilkan nomor tersebut dalam bentuk pesan Toast saat tombol ditekan. Aplikasi berhasil menangkap input dari pengguna, memprosesnya, dan memberikan umpan balik secara instan dalam bentuk notifikasi ringan tanpa berpindah halaman. Jika input kosong, aplikasi juga secara otomatis menampilkan peringatan agar pengguna mengisi nomor terlebih dahulu. Dengan menggunakan komponen `EditText`, `Button`, dan `Toast`, serta memanfaatkan `ConstraintLayout`, aplikasi ini telah berhasil menunjukkan interaksi dasar antara pengguna dan sistem dalam pengembangan Android native menggunakan Kotlin.
